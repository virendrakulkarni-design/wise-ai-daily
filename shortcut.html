Share to AI Daily

Two ways to get any link into the app fast — pick whichever fits how you browse.

Option 1 — Real share-sheet button (best)
Build a tiny 2-step Shortcut using Apple's own Shortcuts app. Takes about a minute, and once it's built it shows up as "AI Daily" in the Share Sheet of every app — YouTube, Instagram, Facebook, X, Safari, all of them.
1
Open the Shortcuts app It's pre-installed on every iPhone. Tap the + button top-right to create a new shortcut.
2
Add action: "Get URLs from Input" Tap Add Action, search for Get URLs from Input, and add it.
3
Add action: "Open URLs" Search for Open URLs and add it below the first action. Tap on its URL field.
4
Type this text, then insert the variable In the URL field type the text below, then tap right after it and insert the Provided Input variable from step 2 (it appears above the keyboard):
https://virendrakulkarni-design.github.io/wise-ai-daily/?share=
5
Rename & enable sharing Tap the shortcut's name at the top → rename to AI Daily. Tap the settings icon (⚙️) → turn on Show in Share Sheet → set accepted types to URLs and Safari web pages.
✓
Done — test it Open any video or link → tap Share → scroll down → tap AI Daily. It opens the app and drops the link straight into the summarizer.
or

Option 2 — One-tap clipboard paste

No setup needed. Copy any link with Share → Copy Link, then open AI Daily and tap the Paste & Summarize button — it reads your clipboard automatically, no typing or manual pasting required.

Try it now
Nothing is uploaded when you build the Shortcut — it only passes the link's text to AI Daily, which you already control with your own Groq API key.
